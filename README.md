# AKR Credit Capital

> Building Possibilities Together

A modern financial management and credit portfolio application built with React, Vite, TypeScript, and Tailwind CSS.

## Getting Started

### Installation
```bash
npm install
```

### Development Server
```bash
npm run dev
```

### Production Build
```bash
npm run build
```

## Features
- Responsive consumer dues & portfolio management
- Administrative control portal
- Secure and modular frontend architecture

## Tech Stack
- React 18
- TypeScript
- Vite
- Tailwind CSS
- Lucide React
